Find your symptom below. If it is not here, open an issue with what you did, what you expected and the exact messages (a photo of the screen is fine).

Gathering information

$ cat /etc/os-release                    # systemLinux version
$ uname -r                               # kernel
$ cat /proc/cmdline                      # kernel parameters
$ sudo dmesg | tail -50                  # latest kernel messages
$ dinitctl list                          # services
$ lsblk -f                               # disks and file systems

The ISO

  • The stick does not show up in the boot menu: check the download's checksum, write it again with dd (not as a file copy), try another USB port, and turn Secure Boot off.
  • "could not find the live medium": the initramfs cannot see the stick. Try another port (USB 2), the copy to RAM entry, or another stick. In the shell it opens, cat /proc/partitions shows what it sees.
  • Black screen after the boot menu: pick debug shell to see the messages, or press e and add nomodeset.

Boot problems

  • Firmware says "no bootable device": GRUB is not installed where the firmware looks. On UEFI, install the fallback (grub-install --removable, GRUB); on BIOS, check that you installed to the disk (/dev/sda) and that a GPT disk has a BIOS boot partition.
  • "grub>" or "grub rescue>" prompt: see GRUB.
  • "[live] could not find the root partition (UUID=...)": the UUID on the root= line is wrong, or the disk's driver is missing. In the shell, run blkid and compare. Fix grub.cfg from the live ISO.
  • "could not mount ... on /": the file system is damaged or the type is unknown. Check it from the live ISO with e2fsck -f /dev/sdXN.
  • Kernel panic "VFS: Unable to mount root fs": the initrd line is missing in grub.cfg, so the kernel tried to mount root by itself.
  • The boot stops at a service: see dinit.
  • No login prompt, but the system runs: switch consoles (Alt+F1); the screen may have stayed on boot messages.

Logging in

  • "Login incorrect": check the keyboard layout (the console starts in US layout until /etc/vconsole.conf is read). Reset the password with init=/bin/bash.
  • sudo or su: "operation not permitted": an install from 0.2.3 or older has wrong file owners; install 0.2.4 or newer.
  • "alex is not in the sudoers file": see sudo.

Network

  • No Wi-Fi device: firmware, then Wireless.
  • Connected but no internet: ping 1.1.1.1 works but names fail: DNS, see Network configuration.
  • Downloads fail with certificate errors: the clock is wrong; set it (System time).

Building software

  • A port fails to build: rebuild with -k, find the first error, report it (get).
  • "Killed" or "out of memory" during a build: use fewer jobs (-j 2), add swap, build in /var/tmp (TMPDIR=/var/tmp).
  • "No space left on device" during a build: /tmp is in memory; use TMPDIR=/var/tmp, and check df -h.
