Wi-Fi is handled by NetworkManager, like wired networks. Most Wi-Fi cards need firmware.

Is the card there?

$ nmcli device                           # a "wifi" device, e.g. wlan0 or wlp3s0
$ rfkill                                 # is it blocked?
$ sudo dmesg | grep -iE 'wlan|wifi|firmware'
  • No wifi device and a firmware error in dmesg: sudo get install linux-firmware, reboot.
  • Blocked (soft blocked: yes): rfkill unblock wifi. hard blocked: yes means a switch or key on the laptop.

Connecting

$ nmcli device wifi list
$ sudo nmcli device wifi connect "MyNetwork" password "secret"
$ sudo nmcli device wifi connect "Hidden" password "secret" hidden yes

The connection is saved and joined again automatically. sudo nmtui offers the same with a list to pick from.

WPA2/WPA3 Enterprise (eduroam, company networks)

$ sudo nmcli connection add type wifi con-name eduroam ssid eduroam \
    wifi-sec.key-mgmt wpa-eap 802-1x.eap peap 802-1x.phase2-auth mschapv2 \
    802-1x.identity "you@university.edu" 802-1x.password "secret"
$ sudo nmcli connection up eduroam

Ask your network's administrators for the EAP method and the CA certificate (802-1x.ca-cert /path/to/ca.pem).

iwd

iwd is Intel's Wi-Fi daemon, an alternative to wpa_supplicant with its own tool, iwctl. Use it instead of NetworkManager's Wi-Fi, not next to it:

$ sudo get install iwd
$ sudo dinitctl enable iwd
$ iwctl station wlan0 scan
$ iwctl station wlan0 connect "MyNetwork"

To let NetworkManager use iwd as its Wi-Fi backend instead, put

[device]
wifi.backend=iwd

in /etc/NetworkManager/conf.d/iwd.conf and restart NetworkManager (only if NetworkManager was built with iwd support).

Troubleshooting

  • Connects, then drops every few minutes: turn off power saving for the card: sudo iw dev wlan0 set power_save off (sudo get install iw).
  • "Secrets were required, but not provided": wrong password, or the network uses WPA3 only and the card does not support it.
  • Slow on 5 GHz or not seeing 5 GHz networks: set your country: sudo iw reg set FR.
