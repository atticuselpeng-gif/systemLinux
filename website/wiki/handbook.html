The systemLinux Handbook installs systemLinux by hand, one step at a time, the way the Gentoo Handbook does: you partition the disk yourself, extract the stage tarball onto it, enter it with chroot, configure it and install a bootloader. Nothing is hidden, so when you are done you know how your system is put together and how to repair it.

If you only want a working system quickly, the quick installer (systemlinux-install) does all of it for you after a few questions.

What you get

  • An ordinary, writable root file system (ext4) on the partition you choose, with everything in /usr and configuration in /etc.
  • dinit as PID 1 (there is no systemd), eudev for devices, NetworkManager for the network.
  • The build toolchain (GCC, make, CMake, Meson, Python, Perl) already installed, so get can build any of the over 1600 ports from source.
  • A console system. A desktop (Sway or i3) is one chapter away.

Chapters

  1. Installation media: hardware requirements, downloading and checking the ISO, writing it to a USB stick.
  2. Booting the live system: the boot menu, the keyboard, getting online, UEFI or BIOS.
  3. Preparing the disks: partition layouts for UEFI and BIOS, file systems, swap, encryption, mounting.
  4. Installing the stage: downloading, checking and extracting the stage tarball (or copying the system from the ISO without a network).
  5. Entering the new system: chroot, DNS, the ports tree.
  6. Configuring the system: fstab, host name, time zone, locale, keyboard, network, passwords and your user account.
  7. Kernel and initramfs: what ships with the stage, firmware, kernel modules.
  8. Bootloader: GRUB for UEFI and for legacy BIOS, its configuration, encryption.
  9. Finalizing: leaving the chroot, rebooting, the first login, what to do next.

Conventions

Commands start with a prompt that tells you where to run them:

PromptWhere
#as root in the live system (it logs you in as root)
(chroot) #as root inside the new system, after chapter 5
$as your normal user on the installed system

Device names are examples. /dev/sda is the first SATA or USB disk, /dev/nvme0n1 the first NVMe SSD and /dev/vda a virtual disk in QEMU. NVMe and MMC disks put a p before the partition number: /dev/nvme0n1p2, but /dev/sda2. Always check yours with lsblk before you type a command that writes to a disk.

Note: Boxes like this one add details. Tip boxes are shortcuts, and Warning boxes mark steps that can destroy data.

Versions

The stage install needs systemLinux 0.2.5 or newer. From that release on, every release publishes systemLinux-stage-VERSION-x86_64.tar.xz next to the ISO, and its initramfs can boot an ordinary root partition (root=UUID=...). Older releases can only be installed with systemlinux-install.

Getting help

Read Troubleshooting first. If you are stuck, or a step in this Handbook is wrong, open an issue and say which chapter and step, what you typed and what it printed.
