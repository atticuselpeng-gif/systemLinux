A list of things most people set up after installing systemLinux, in a sensible order. Pick what you need.

System

A user account and sudo

Work as a normal user and use sudo for administration. The Handbook and the quick installer set this up; check with sudo whoami.

Firmware

sudo get install linux-firmware if anything (Wi-Fi, GPU, Bluetooth) does not work. See Firmware.

Time synchronization

sudo get install chrony && sudo dinitctl enable chronyd. See System time.

Swap for big builds

With less than 8 GB of RAM, add disk swap before building a desktop or a browser: Swap.

Backups

Decide now where your backups go: System maintenance.

Software

Learn get

get search, get install, get remove, get sync: get. Run sudo get sync now and then for a newer ports tree.

Command-line tools

KindPorts
Editorsnano (in the base system), vim, neovim
Shellsbash (default), zsh, fish; change with chsh -s /usr/bin/zsh
Toolsgit, htop, tmux, rsync, fastfetch
Hardware infopciutils (lspci), usbutils (lsusb)

Man pages

man is installed, but the base system's own manual pages are stripped to keep it small. Ports you build with their manual pages install them, and man finds them.

Networking

  • Wi-Fi: Wireless.
  • Remote access: sudo dinitctl enable sshd, then harden it: OpenSSH.
  • A firewall: Network configuration.

Graphical session

  1. sudo get profile desktop-runtime and sudo get install fonts-dejavu
  2. Sway or i3
  3. Sound
  4. A browser: sudo get install firefox-bin
  5. Optionally a login screen: greetd

Details in Graphical session.

Laptops

Brightness, battery, suspend: Laptop.

Console comfort

  • Keyboard layout and font at boot: Linux console.
  • A second login console: Linux console.
  • Your language: Locale.
