When the installed system does not boot or you cannot log in, start it from the outside: boot the live ISO, mount the installed system and chroot into it. Everything can be repaired from there.

Without the ISO: init=/bin/bash

For a lost password or a broken service, this is quickest. In the GRUB menu press e, add init=/bin/bash at the end of the linux line, and boot with Ctrl+X. You get a root shell before dinit starts, with root mounted read-write:

# passwd alex                     # reset a password
# rm /etc/dinit.d/boot.d/broken   # disable a service that hangs the boot
# sync
# echo b > /proc/sysrq-trigger    # reboot at once (dinit is not running, so reboot cannot ask it)

Nothing else is running: no devices beyond the basics, no network. On an image install this works the same.

From the live ISO (Handbook installs)

Boot the ISO, then find the partitions with lsblk -f:

# cryptsetup open /dev/sda3 root              # only if root is encrypted
# mount /dev/sda2 /mnt                        # root (encrypted: /dev/mapper/root)
# mount /dev/sdaX /mnt/boot                   # only with a separate /boot
# mount /dev/sda1 /mnt/boot/efi               # UEFI: the EFI System Partition
# mount --types proc /proc /mnt/proc
# mount --rbind /sys /mnt/sys && mount --make-rslave /mnt/sys
# mount --rbind /dev /mnt/dev && mount --make-rslave /mnt/dev
# cp --dereference /etc/resolv.conf /mnt/etc/
# chroot /mnt /bin/bash

Repair what is broken (below), then exit, umount -R /mnt and reboot.

Image installs

A quick install keeps the system image and your changes apart. Put them together first:

# mkdir -p /mnt/data /mnt/sq /mnt/root
# mount /dev/sdaN /mnt/data                       # the system partition (LUKS: cryptsetup open it first)
# VER=$(ls /mnt/data/boot/images | sort -V | tail -1)
# mount -t squashfs -o loop,ro /mnt/data/boot/images/$VER/rootfs.squashfs /mnt/sq
# mount -t overlay overlay -o lowerdir=/mnt/sq,upperdir=/mnt/data/persist/upper,workdir=/mnt/data/persist/work /mnt/root
# for d in dev proc sys; do mount --rbind /$d /mnt/root/$d; mount --make-rslave /mnt/root/$d; done
# chroot /mnt/root /bin/bash

Your own files, settings and the software you built are all in /mnt/data/persist/upper; copy that folder to back everything up.

Common repairs

ProblemFix, inside the chroot
Forgotten passwordpasswd alex
Not in sudoersusermod -aG wheel alex, and check /etc/sudoers.d/10_wheel with visudo -c
GRUB missing or overwritten by Windowsrun grub-install again (Handbook chapter 8)
Broken grub.cfgedit /boot/grub/grub.cfg; check UUIDs with blkid
Wrong /etc/fstabfix it, check with findmnt --verify
A service hangs the bootremove its link from /etc/dinit.d/boot.d/
A package broke somethingget remove NAME (or get install -f NAME to rebuild it)
Deleted kernel or initramfsextract them again from the stage: Kernel

Recovering files only

To copy your files off a system that cannot be repaired, mount it as above (without chroot) and copy /mnt/home to a USB disk: mount /dev/sdb1 /media && cp -a /mnt/home /media/.
