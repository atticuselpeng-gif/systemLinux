Printing (CUPS)

Printing on systemLinux uses CUPS.

Note: Printing support is basic. The cups-filters collection, which converts documents for most printers, is not packaged yet, so only printers that accept PDF or plain text directly work (many recent network printers do, through "IPP Everywhere" or AirPrint). Packaging cups-filters is a welcome contribution.

Installing

$ sudo get install cups
$ sudo dinitctl enable cupsd
$ sudo usermod -aG lp alex                # to manage printers as alex (log in again)

Adding a printer

Open CUPS' web interface on the computer itself at http://localhost:631 and use Administration, Add Printer. Or from the command line, for a network printer that speaks IPP Everywhere:

$ sudo lpadmin -p office -E -v ipp://192.168.1.50/ipp/print -m everywhere
$ sudo lpoptions -d office                 # make it the default

Printing

$ lp document.pdf                         # to the default printer
$ lp -d office -n 2 document.pdf          # two copies on "office"
$ lpstat -p -d                            # printers and the default
$ lpstat -o                               # waiting jobs
$ cancel -a                               # cancel all jobs
