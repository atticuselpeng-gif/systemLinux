i3 is a tiling window manager for X11. Its Wayland twin is Sway, which uses nearly the same configuration.

Installing

Do the steps in Graphical session first. Then:

$ sudo get install xorg-server xinit xf86-input-libinput i3 i3status dmenu xterm pipewire wireplumber

Starting

$ printf 'exec i3\n' > ~/.xinitrc
$ startx

On the first start i3 offers to write a configuration and asks for the modifier key (Win or Alt). Then add the session services to ~/.config/i3/config:

exec --no-startup-id dinit

Starting X automatically on tty1, in ~/.bash_profile:

if [ -z "$DISPLAY" ] && [ "$(tty)" = /dev/tty1 ]; then
    exec startx
fi

Configuration

Useful additions to ~/.config/i3/config:

exec --no-startup-id setxkbmap fr
bindsym $mod+Return exec xterm
bindsym XF86AudioRaiseVolume exec --no-startup-id wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
bindsym XF86AudioLowerVolume exec --no-startup-id wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bindsym XF86AudioMute exec --no-startup-id wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
bindsym $mod+Escape exec --no-startup-id i3lock -c 000000

Reload with Mod+Shift+C, restart i3 in place with Mod+Shift+R. The i3 User's Guide documents everything. A compositor for transparency and no tearing: picom.

Troubleshooting

See Xorg when X itself does not start. i3's own messages go to the terminal you ran startx from.
