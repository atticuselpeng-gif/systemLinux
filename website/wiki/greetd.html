greetd (login manager)

Related articles
  • Sway
  • Graphical session
  • dinit
Contents
  1. 1 Installing
  2. 2 A session script
  3. 3 Enabling

greetd is a small login manager. With tuigreet it shows a login screen in the console and starts your session after you log in, so you do not have to type sway yourself.

Installing

$ sudo get install greetd tuigreet

The port comes with a dinit service and /etc/greetd/config.toml, which runs tuigreet on tty7 and starts Sway after a login:

[terminal]
vt = 7

[default_session]
command = "/usr/bin/tuigreet --time --remember --cmd sway"
user = "greeter"

The greeter user is created the first time the service starts.

A session script

greetd starts the session command directly, not through a login shell, so the variables set in /etc/profile.d (XDG_RUNTIME_DIR, the D-Bus address, your locale) are missing. Start the session through a small script that reads them first:

$ printf '#!/bin/sh\n. /etc/profile\n[ -f "$HOME/.profile" ] && . "$HOME/.profile"\nexec sway\n' | sudo tee /usr/local/bin/sway-session
$ sudo chmod 755 /usr/local/bin/sway-session

and use it in /etc/greetd/config.toml:

command = "/usr/bin/tuigreet --time --remember --cmd /usr/local/bin/sway-session"

For an X11 session, make the script end with exec startx instead.

Enabling

$ sudo dinitctl enable greetd

The login screen appears on tty7 (Ctrl+Alt+F7); the console login on tty1 stays available. If the session does not start, switch to tty1, log in and run sway by hand to see the error; sudo dinitctl disable greetd turns the login screen off again.
