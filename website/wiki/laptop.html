systemLinux runs on laptops, but there is no elogind or power daemon yet, so a few things a desktop distribution does by itself (suspend on lid close, power profiles) are set up by hand or not available.

First steps

  • Install firmware: sudo get install linux-firmware. Wi-Fi, Bluetooth and GPU power saving depend on it.
  • Connect to Wi-Fi.
  • Touchpads work in Sway and X11 through libinput. Tap-to-click in Sway: input type:touchpad { tap enabled; natural_scroll enabled }.

Battery

$ cat /sys/class/power_supply/BAT0/capacity    # charge in percent
$ cat /sys/class/power_supply/BAT0/status      # Charging, Discharging, Full

i3status and waybar can show it in the bar. Many ThinkPads, ASUS and other laptops can stop charging at a threshold, which makes the battery last longer:

$ echo 80 | sudo tee /sys/class/power_supply/BAT0/charge_control_end_threshold

That lasts until the next boot; to keep it, put the command in a small scripted dinit service.

Screen brightness

$ sudo get install brightnessctl
$ brightnessctl set 50%
$ brightnessctl set 10%+

If it says "Permission denied", the port's udev rule that lets the video group change the brightness is not installed; use sudo brightnessctl. Sway bindings:

bindsym XF86MonBrightnessUp exec brightnessctl set 5%+
bindsym XF86MonBrightnessDown exec brightnessctl set 5%-

If nothing changes, try the kernel parameter acpi_backlight=native or acpi_backlight=vendor.

Suspend

Without elogind there is no loginctl suspend. Suspend to RAM directly through the kernel:

$ sudo sh -c 'echo mem > /sys/power/state'

cat /sys/power/mem_sleep shows which kind of suspend is used (s2idle or deep). Closing the lid does nothing by default. Suspend on lid close needs an ACPI event handler such as acpid (sudo get install acpid), which has no service or handler script in its port yet. Hibernation is not supported.

With Sway, lock the screen first with swaylock.

Power saving

  • Check what draws power: cat /sys/class/power_supply/BAT0/power_now (microwatts).
  • Intel CPUs: cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference; set power or balance_power on battery (as root, for every CPU).
  • TLP is in the ports tree (sys-app/tlp) but has no service yet.
