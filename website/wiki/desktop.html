systemLinux installs as a console system. This page explains what a graphical session needs and how the pieces fit together; Sway (Wayland) and i3 (X11) have step-by-step pages.

What you need

  1. Firmware for your GPU (AMD and NVIDIA always, Intel for power saving): sudo get install linux-firmware. See Graphics drivers.
  2. Fonts and themes: the desktop-runtime profile and a font port: 
    $ sudo get profile desktop-runtime
$ sudo get install fonts-dejavu
  3. Groups: your user in video, audio and input (id shows them; see Users and groups).
  4. A window manager or compositor: Sway or i3. Other ports exist (dwm, xfce4-session, ...), not all verified.
  5. Sound: PipeWire.

Expect the first desktop install to take hours on a laptop: Mesa, LLVM, GTK and their dependencies are built from source. Use -bin ports where they exist (firefox-bin).

How a session starts without logind

There is no systemd-logind or elogind. Their jobs are done by:

JobDone by
Access to the GPU and input devices for Wayland compositorsseatd (sudo dinitctl enable seatd; members of video may use it)
Access for X11the video and input groups
/run/user/UID (XDG_RUNTIME_DIR)pam_exec at login (/usr/libexec/systemlinux-rundir) and /etc/profile.d/xdg-runtime.sh
The session D-Busyour own user dinit
Login screenthe console, or greetd

Session services

Start a user dinit from your window manager. It runs the services in /etc/dinit.d/user/boot.d: the session D-Bus, and PipeWire, pipewire-pulse and WirePlumber when those ports are installed. Add one line to your configuration:

SessionLineFile
Swayexec dinit~/.config/sway/config
i3exec --no-startup-id dinit~/.config/i3/config
any X11 sessiondinit & before the window manager~/.xinitrc

Programs started from the session find the bus through DBUS_SESSION_BUS_ADDRESS, set at login. Your own user services go in ~/.config/dinit.d/.
