Starting the ISO

Plug in the stick and turn the computer on. Open the firmware's boot menu (usually F12, F11, F10, F8 or Esc, shown on the first screen) and pick the stick. If it appears twice, once with "UEFI" in its name, the UEFI entry boots in UEFI mode and the other one in legacy BIOS mode: install in the same mode you will boot the installed system in.

The systemLinux boot menu offers:

EntryWhat it does
systemLinux VERSIONThe normal live system. Starts after 3 seconds.
copy to RAMLoads the whole system into memory first, so you can pull the stick out (needs about 2 GB of RAM more).
serial consoleAlso uses the first serial port (115200 baud), for servers and headless virtual machines.
debug shellShows every boot message and stops in a shell right before the system starts.

Press e on an entry to change its kernel command line for one boot, see Kernel parameters.

The live system logs you in as root on the first console. Nothing is written to any disk until you do it yourself. Everything you change in the live system is kept in memory and gone after a reboot.

Keyboard layout

The console starts with the US layout. Load yours with loadkeys; the available layouts are under /usr/share/keymaps:

# find /usr/share/keymaps -name '*.map.gz' | sed 's|.*/||; s|\.map\.gz||' | sort | less
# loadkeys fr                          # French AZERTY; de, uk, es, it, dvorak, ...

A bigger console font helps on high-resolution screens: setfont with a font from /usr/share/consolefonts.

UEFI or BIOS?

Check which mode the live system was started in, because the partition layout and the bootloader depend on it:

# ls /sys/firmware/efi

If the directory exists you booted in UEFI mode. If ls says "No such file or directory", you booted in legacy BIOS mode.

Getting online

You need a network to download the stage tarball in chapter 4. Without one, you can still install the copy of the system that is on the ISO.

Wired

Ethernet connects by itself. Check that you have an address and can reach the internet:

# ip addr
# ping -c 3 kernel.org

Wi-Fi

NetworkManager manages the network. Connect to Wi-Fi with nmcli, or use the menus of nmtui:

# nmcli device wifi list
# nmcli device wifi connect "MyNetwork" password "secret"
# nmcli device status

If no Wi-Fi device shows up, the card probably needs firmware that is not on the ISO. Use Ethernet, or share the connection of a phone over USB ("USB tethering"), which shows up as an Ethernet device. See Wireless for more.

Hidden networks, proxies and static addresses

See Network configuration. For a proxy, export https_proxy and http_proxy: curl and get use them.

Installing over SSH

Tip: To install from another computer (copy and paste the commands), give root a password in the live system and start the SSH server: 
# passwd
# dinitctl start sshd
# ip addr                              # the live system's address
Then ssh root@ADDRESS from the other computer.

The clock

Downloads over HTTPS fail if the clock is far off. Check it with date; if it is wrong, set it (in UTC):

# date -u -s '2026-10-17 14:30'
