Building the ISO

Related articles
  • Contributing
  • Package profiles
  • Initramfs
Contents
  1. 1 Requirements
  2. 2 Building
  3. 3 Testing
  4. 4 Releasing

build_iso.sh in the repository builds a release: the ISO, the stage tarball, the package profiles and the ports tree archive.

Requirements

A glibc-based x86_64 Linux host with sudo (Debian, Ubuntu, Fedora, Arch, Gentoo; musl hosts do not work, because some of the host's tools are copied into the image with their libraries), about 30 GB free, and:

  • GRUB with both the i386-pc and x86_64-efi platform files, xorriso, mtools
  • squashfs-tools, cpio, zstd, xz
  • busybox (static is best), cryptsetup, efibootmgr, dosfstools
  • gcc, g++, make, curl, gperf, pkg-config, kmod with its headers, libblkid headers, binutils

The script lists anything missing and prints the install command for Debian and Fedora. On Debian/Ubuntu:

$ sudo apt install xorriso squashfs-tools mtools cpio busybox cryptsetup efibootmgr dosfstools \
    grub-efi-amd64-bin grub-pc-bin g++ curl gperf pkg-config kmod libkmod-dev libblkid-dev zstd xz-utils binutils grub-common

Building

$ git clone https://github.com/tortr-rs/systemLinux && cd systemLinux
$ ./build_iso.sh                          # or: make iso

Run it from a normal terminal; it asks for your sudo password. It:

  1. checks the ports tree and the dinit services
  2. downloads and verifies the newest Ubuntu generic kernel
  3. builds dinit, eudev and GNU bash, and installs get and the ports tree into the base tree (rootfs/)
  4. copies the base tree to a staging directory, builds the real sudo inside it, adds the boot tools from the host, strips documentation and the non-@keep profiles
  5. builds the initramfs and puts it, with the kernel and modules, into the stage
  6. packs the stage twice: as systemLinux-stage-VER-x86_64.tar.xz and as the ISO's squashfs
  7. writes the ISO's GRUB menu and masters the hybrid BIOS/UEFI ISO
  8. packs the profiles and ports.tar.xz into profiles-out/

Results, named after VERSION: systemLinux-VER-x86_64.iso, systemLinux-stage-VER-x86_64.tar.xz (each with a .sha256), and profiles-out/.

Tip: Without a suitable host, push a branch and open a pull request: the Build ISO GitHub workflow builds everything, boots it, and offers the files as a download (gh run download RUN-ID).

Testing

$ make check                              # ports and dinit services, no build
$ tools/tests/boot-smoke.sh bios           # boot the ISO in QEMU with SeaBIOS
$ OVMF=/usr/share/edk2/x64/OVMF.4m.fd tools/tests/boot-smoke.sh uefi

The smoke test boots through GRUB, the kernel and the initramfs and waits until dinit reaches its boot service.

Releasing

Pushing a tag vVERSION runs the release workflow: it builds and tests the ISO, checks the checksums and publishes the ISO, the stage tarball, the profiles, ports.tar.xz and SHA256SUMS as a GitHub release.
