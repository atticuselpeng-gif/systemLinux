Bluetooth

Bluetooth on systemLinux is BlueZ: the bluetoothd daemon and the bluetoothctl tool.

Installing

$ sudo get install bluez
$ sudo dinitctl enable bluetoothd

Most Bluetooth chips (Intel, Realtek, MediaTek) need firmware. If the adapter is blocked, unblock it with rfkill unblock bluetooth (rfkill lists the radios).

Pairing a device

$ bluetoothctl
[bluetooth]# power on
[bluetooth]# agent on
[bluetooth]# default-agent
[bluetooth]# scan on                    # put the device in pairing mode; wait for its address
[NEW] Device 3C:4D:BE:84:1F:BC MX Keys
[bluetooth]# pair 3C:4D:BE:84:1F:BC
[bluetooth]# trust 3C:4D:BE:84:1F:BC     # reconnect without asking
[bluetooth]# connect 3C:4D:BE:84:1F:BC
[bluetooth]# quit

Keyboards and mice work right away. To power the adapter on at every start of bluetoothd, set AutoEnable=true in the [Policy] section of /etc/bluetooth/main.conf.

Audio

Note: Bluetooth headphones and speakers do not work yet: the pipewire port is built without its Bluetooth module. Enabling it (-Dbluez5=enabled in the recipe, plus the codec libraries) is a welcome contribution.

Troubleshooting

  • "No default controller available": bluetoothd is not running (dinitctl status bluetoothd), the chip's firmware is missing (dmesg | grep -i bluetooth), or the radio is blocked (rfkill).
  • Pairing fails: remove the device (remove ADDRESS in bluetoothctl), reset it, and pair again with an agent on.
