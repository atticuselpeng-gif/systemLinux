Sway

Sway is a tiling Wayland compositor, compatible with i3's configuration. It is the recommended graphical session on systemLinux.

Installing

Do the steps in Graphical session first (firmware, the desktop-runtime profile, a font, groups). Then:

$ sudo get install sway foot wmenu pipewire wireplumber
$ sudo dinitctl enable seatd

sway pulls in wlroots, Mesa and libinput. foot is the terminal and wmenu the program launcher of Sway's default configuration. seatd gives Sway access to the GPU and input devices.

Configuration

Start from the default configuration and add the session services:

$ mkdir -p ~/.config/sway
$ cp /etc/sway/config ~/.config/sway/config
$ echo 'exec dinit' >> ~/.config/sway/config

exec dinit starts your session services (D-Bus, PipeWire). Useful additions:

# keyboard layout and touchpad
input type:keyboard {
    xkb_layout fr
    xkb_options caps:escape
}
input type:touchpad {
    tap enabled
    natural_scroll enabled
}

# screens: see "swaymsg -t get_outputs"
output eDP-1 scale 1.5
output * bg #285577 solid_color          # or: output * bg ~/wallpaper.png fill

# volume and brightness keys
bindsym XF86AudioRaiseVolume exec wpctl set-volume -l 1.5 @DEFAULT_AUDIO_SINK@ 5%+
bindsym XF86AudioLowerVolume exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bindsym XF86AudioMute exec wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
bindsym XF86MonBrightnessUp exec brightnessctl set 5%+
bindsym XF86MonBrightnessDown exec brightnessctl set 5%-

# screenshot of a region to the clipboard (grim, slurp, wl-clipboard)
bindsym Print exec grim -g "$(slurp)" - | wl-copy

Reload with Mod+Shift+C. man 5 sway documents everything (with man pages installed), or see the Sway wiki.

Starting

Log in on the console and run:

$ sway

To start it automatically when you log in on tty1, add to the end of ~/.bash_profile:

if [ -z "$WAYLAND_DISPLAY" ] && [ "$(tty)" = /dev/tty1 ]; then
    exec sway
fi

Or use the greetd login manager.

First keys

KeysAction
Mod+Enterterminal (foot)
Mod+Dlauncher (wmenu)
Mod+Shift+Qclose the window
Mod+1 ... 9workspaces
Mod+arrowsmove the focus
Mod+Shift+Eexit Sway

Mod is the "Windows" key (Mod4).

Locking and idle

$ sudo get install swaylock swayidle
exec swayidle -w timeout 300 'swaylock -f' timeout 600 'swaymsg "output * power off"' \
    resume 'swaymsg "output * power on"' before-sleep 'swaylock -f'
bindsym $mod+Escape exec swaylock -f

Troubleshooting

Run sway -d 2> ~/sway.log and read the first errors.

  • "Failed to open any DRM device" / "Could not connect to seatd": start seatd (sudo dinitctl start seatd) and check that you are in video (id; log in again after usermod -aG video).
  • "XDG_RUNTIME_DIR is not set": log in on the console, not with su; the directory is created at login (ls -ld /run/user/$(id -u)).
  • Black screen in a virtual machine: give it a virtio GPU (QEMU: -vga virtio) or try WLR_RENDERER=pixman sway.
  • No text in programs, or squares instead of letters: no font is installed: sudo get install fonts-dejavu.
  • No sound: see PipeWire.
