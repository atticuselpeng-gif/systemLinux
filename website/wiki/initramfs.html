Initramfs

Contents
  1. 1 What it contains
  2. 2 What it does
  3. 3 One initramfs for every machine

The initramfs (/boot/initrd.img) is a small file system the kernel unpacks into memory and starts before the real system. Its job is to make the root file system reachable: load the disk drivers, find the partition, unlock it, mount it, and hand over to dinit.

What it contains

  • /init, a shell script (the source is tools/live-image/init)
  • busybox, for the shell and basic tools
  • cryptsetup, for LUKS
  • the kernel modules for disks and file systems: every SATA, SCSI, NVMe, USB storage, MMC and virtio driver, plus ext4, XFS, Btrfs, F2FS, FAT, exFAT, ISO 9660, squashfs, overlayfs and dm-crypt

Look inside with zstd -dc /boot/initrd.img | cpio -t | less (cpio is not in the base system: sudo get install cpio).

What it does

  1. Mounts /proc, /sys and /dev, and reads the kernel parameters.
  2. Loads the storage modules and every driver the hardware asks for.
  3. Depending on the parameters, finds:
    • with root=: the root partition (a Handbook install). If it starts with a LUKS header, asks for the passphrase and opens it as /dev/mapper/root. Mounts it read-write on the new root.
    • with systemlinux.image=: the system partition of an image install, its squashfs image and the writable layer in /persist.
    • with neither: the live medium, on any disk or inside an ISO file on a disk.
  4. Moves /proc, /sys and /dev into the new root, mounts /run, and runs switch_root to /usr/bin/dinit.

When something is missing it prints why and opens a shell ("[live] starting a shell"). Fix the problem there (for example cryptsetup open by hand, or look at /proc/partitions), then type exit and it tries again.

One initramfs for every machine

The initramfs is the same on the ISO and on every installed system, and does not depend on your hardware or configuration. You never have to regenerate it after changing /etc. It only changes with the kernel: the modules inside it must match the kernel version, which is why a kernel update always copies both files together (Kernel).

Note: There is no tool to build an initramfs on an installed system yet. It is made by tools/live-image/build-initrd.sh during the ISO build.
