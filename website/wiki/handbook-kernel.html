7. Kernel and initramfs

Related articles
  • Kernel
  • Initramfs
  • Firmware
  • Kernel parameters
Contents
  1. 1 The kernel
  2. 2 The initramfs
  3. 3 Firmware
  4. 4 Updating the kernel

Unlike Gentoo, there is no kernel to configure and compile in this chapter: the stage already contains a ready kernel, its modules and an initramfs. This chapter explains what they are and installs the firmware most laptops need.

The kernel

/boot/vmlinuz is the newest Ubuntu generic kernel at the time of the release, the same one the live ISO boots. Nearly every driver is built as a module, so it runs on almost any x86_64 computer. The modules are in /usr/lib/modules/VERSION:

(chroot) # ls /usr/lib/modules           # one directory, named after the kernel version (...-generic)

Drivers load by themselves when eudev sees the hardware. See Kernel for loading, blacklisting and passing options to modules.

The initramfs

/boot/initrd.img is a small archive the kernel unpacks into memory before your root file system is reachable. It loads the storage drivers, finds the partition named by root= on the kernel command line, asks for the passphrase if that partition is encrypted with LUKS, mounts it and starts dinit. It is generic: it contains the drivers for every common disk controller and the ext4, XFS, Btrfs, F2FS and FAT file systems, so you do not need to build one for your computer. See Initramfs.

Firmware

Many Wi-Fi cards, Bluetooth chips and GPUs (Intel Wi-Fi, AMD graphics, Realtek, MediaTek, ...) need firmware files that the kernel loads when the driver starts. They are not in the stage. Install them with:

(chroot) # get install linux-firmware

It is kernel.org's firmware collection, about 950 MB compressed. Without it a machine that needs it starts, but the device stays off: typically no Wi-Fi, or graphics without acceleration. Virtual machines and most desktop computers with wired network and Intel graphics work without it; you can install it later. See Firmware.

Note: Processor microcode updates are part of linux-firmware (intel-ucode, amd-ucode), but the kernel only applies them at boot when they are loaded early, which the initramfs does not do yet.

Updating the kernel

A new release comes with a new kernel, modules and initramfs. Until a linux port exists, update them from a newer stage tarball: see Kernel.
