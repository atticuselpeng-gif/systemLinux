Kernel parameters are options given to the kernel when it starts. The kernel uses some of them; the systemLinux initramfs reads others.

Setting them

For one boot

In the GRUB menu, select an entry and press e. Go to the line that starts with linux, add or remove options at its end, and press Ctrl+X (or F10) to boot. Nothing is saved.

Permanently

Edit the linux lines in /boot/grub/grub.cfg:

linux /boot/vmlinuz root=UUID=0f4c...e1 quiet loglevel=3 mitigations=auto

Check what the running kernel was started with: cat /proc/cmdline.

systemLinux parameters

Read by the initramfs (/init in /boot/initrd.img).

Installed systems

root=UUID=... | root=LABEL=... | root=/dev/...
the root partition of a Handbook install. If it is LUKS encrypted, the initramfs asks for the passphrase, opens it as /dev/mapper/root and mounts that. Always mounted read-write.
rootfstype=TYPE
the root file system type (default: detected)
rootflags=OPTIONS
mount options for root, e.g. rootflags=noatime or rootflags=subvol=@ for Btrfs
init=PATH
the program to run as PID 1 instead of /usr/bin/dinit; init=/bin/bash gives a root shell without passwords (Recovery)
systemlinux.image=PATH systemlinux.data=UUID=...
an image install: the squashfs image to run and the partition that holds it (written by systemlinux-install)
systemlinux.wait=SECONDS
how long to wait for the root partition or live medium (default 60)
systemlinux.debug=1
open a shell right before switching to the real system
systemlinux.shell=1
open a shell before looking for any disk

Live ISO

systemlinux.toram=1
copy the system into memory, so the stick can be removed
systemlinux.label=NAME
the volume label of the medium (default SYSTEMLINUX)
systemlinux.iso=PATH
the ISO file to use on a stick with several (Ventoy)

Common kernel parameters

quiet / loglevel=3
fewer messages at boot; remove them to see everything
console=tty0 console=ttyS0,115200
boot messages on the screen and on the first serial port
nomodeset
no graphics driver until the system is up: for a black screen at boot
module_blacklist=nouveau,pcspkr
never load these modules
i915.enable_psr=0
module options work here too (MODULE.OPTION=VALUE)
mitigations=off
turn off CPU vulnerability mitigations: faster, less safe
consoleblank=0
never blank the console
acpi_backlight=vendor | native
for laptops whose brightness keys do nothing
systemd.*
ignored: there is no systemd

The complete list is the kernel's own kernel-parameters page.
