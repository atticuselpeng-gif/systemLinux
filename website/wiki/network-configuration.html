systemLinux manages the network with NetworkManager, which starts at every boot. Ethernet connects by itself with DHCP; everything else is configured with nmcli (commands) or nmtui (menus in the terminal).

Checking the connection

$ nmcli                                  # overview: devices, addresses, DNS
$ nmcli device status
$ ip addr                                # addresses of every interface
$ ip route                               # routes; "default via" is the gateway
$ ping -c 3 1.1.1.1                      # reachability without DNS
$ ping -c 3 kernel.org                   # with DNS

If the IP ping works and the name ping does not, DNS is the problem (below).

Connections

NetworkManager keeps connections (settings) separate from devices (hardware). Changing connections needs root.

$ nmcli connection show                    # saved connections
$ sudo nmcli connection up "Wired connection 1"
$ sudo nmcli connection down "Wired connection 1"
$ sudo nmcli connection delete "OldNetwork"
$ sudo nmtui                               # the same with menus

Saved connections are files in /etc/NetworkManager/system-connections/.

Static address

$ sudo nmcli connection modify "Wired connection 1" \
    ipv4.method manual ipv4.addresses 192.168.1.20/24 ipv4.gateway 192.168.1.1 ipv4.dns "192.168.1.1 1.1.1.1"
$ sudo nmcli connection up "Wired connection 1"

Back to DHCP: ipv4.method auto ipv4.addresses "" ipv4.gateway "" ipv4.dns "".

DNS

NetworkManager writes the name servers it gets from DHCP into /etc/resolv.conf. To use your own on one connection:

$ sudo nmcli connection modify "Wired connection 1" ipv4.ignore-auto-dns yes ipv4.dns "9.9.9.9 1.1.1.1"
$ sudo nmcli connection up "Wired connection 1"
$ cat /etc/resolv.conf

Look up names with getent hosts kernel.org; for dig install bind or ldns (drill).

Host name

The host name is read from /etc/hostname at boot. Change it there and in /etc/hosts, then sudo hostname NEWNAME for the running system.

Without NetworkManager

For a quick test, or on a server, the ip command configures an interface by hand (lost at reboot):

$ sudo ip link set enp1s0 up
$ sudo ip addr add 192.168.1.20/24 dev enp1s0
$ sudo ip route add default via 192.168.1.1
$ echo 'nameserver 1.1.1.1' | sudo tee /etc/resolv.conf

To stop NetworkManager for good, remove depends-on = NetworkManager from /etc/dinit.d/network.

VPN

wireguard-tools and openvpn are in the ports tree. A WireGuard configuration file can be imported into NetworkManager:

$ sudo get install wireguard-tools
$ sudo nmcli connection import type wireguard file /etc/wireguard/wg0.conf

Firewall

No firewall is active by default, and no network service listens unless you enable one (for example sshd). For a firewall, install nftables (sudo get install nftables), write the rules in a file and load them with sudo nft -f FILE; to load them at every boot, add a scripted dinit service that runs that command.
