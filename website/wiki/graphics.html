The kernel has the drivers that set the screen mode (KMS) for Intel, AMD and NVIDIA (nouveau) GPUs and for virtual machines. 3D acceleration (OpenGL) comes from Mesa, which Wayland compositors and X11 both use.

Firmware: sudo get install linux-firmware (Firmware).

Note: NVIDIA's proprietary driver is not available. nouveau works for desktops but is slow on recent NVIDIA cards. Vulkan drivers are not built yet; the vulkan-loader port exists for programs that link to it.

Installing Mesa

Mesa is pulled in automatically by sway, xorg-server and every other graphical port. To install it alone:

$ sudo get install mesa

Mesa is a big build (it needs LLVM for the AMD and software drivers): expect it to take a while on the first desktop install.

Checking

$ ls /dev/dri                             # card0 and renderD128: the kernel driver works
$ sudo dmesg | grep -iE 'drm|i915|amdgpu|nouveau'
$ sudo get install mesa-demos && eglinfo | grep -i renderer   # inside the graphical session

If the renderer is "llvmpipe", Mesa is drawing in software: the GPU driver or its firmware is missing, or your user is not in the video group.

Troubleshooting

  • Black screen during boot: boot once with nomodeset (Kernel parameters) to get a console, then install the firmware.
  • Tearing or flicker on Intel laptops: try i915.enable_psr=0.
  • Sway says "Failed to open any DRM device": seatd is not running or you are not in video; see Sway.
