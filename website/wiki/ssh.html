OpenSSH

OpenSSH is part of the base system: the client (ssh, scp, sftp) and the server (sshd).

Client

$ ssh alex@server.example.org
$ ssh -p 2222 alex@server.example.org      # another port
$ scp file.txt alex@server:/tmp/
$ sftp alex@server

Keys

Log in with a key instead of a password:

$ ssh-keygen -t ed25519                  # creates ~/.ssh/id_ed25519 and id_ed25519.pub
$ ssh-copy-id alex@server                # puts the public key on the server

Settings per host go in ~/.ssh/config:

Host server
    HostName server.example.org
    User alex
    Port 2222

Server

$ sudo dinitctl enable sshd

The sshd service first runs ssh-keygen, which creates the host keys in /etc/ssh/ if they are missing (on the first start of a new install). Check that it listens: ss -tlnp | grep :22.

Configuration

/etc/ssh/sshd_config, or better a file in /etc/ssh/sshd_config.d/. Recommended once your key works:

# /etc/ssh/sshd_config.d/10-local.conf
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no

Check and apply: sudo sshd -t && sudo dinitctl restart sshd.

Warning: Keep your current session open while you test a new configuration from a second terminal, or you may lock yourself out of a remote machine.
