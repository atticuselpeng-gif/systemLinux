Sound (PipeWire)

Related articles
  • Graphical session
  • dinit
  • Bluetooth
Contents

  3. 3 Volume and devices
  4. 4 Configuration
  5. 5 Troubleshooting

PipeWire is the sound server of systemLinux. It replaces PulseAudio (programs that speak PulseAudio work unchanged, through pipewire-pulse) and JACK, and it handles screen sharing on Wayland. WirePlumber is its session manager: it picks the output device and remembers volumes.

Installing

$ sudo get install pipewire wireplumber
==> user services installed: they start with your session's dinit (exec dinit in your sway/i3 config)

Your user must be in the audio group (id shows it; the Handbook adds it).

Starting

PipeWire runs as your user, not as a system service. The ports install three user services: pipewire, pipewire-pulse and wireplumber, all started with your session's dinit. Start that dinit from your window manager's configuration (see Graphical session):

# ~/.config/sway/config
exec dinit

Check that they run, from a terminal in the session:

$ dinitctl list
[{+}     ] boot
[{+}     ] dbus
[{+}     ] pipewire
[{+}     ] pipewire-pulse
[{+}     ] wireplumber

Without a graphical session (on the console), start it by hand: dinit & after logging in.

Volume and devices

wpctl comes with WirePlumber:

$ wpctl status                           # devices, sinks (outputs), sources (inputs); * marks the default
$ wpctl set-default 46                   # make sink 46 the default output
$ wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
$ wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
$ wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle

Sway key bindings for the volume keys:

bindsym XF86AudioRaiseVolume exec wpctl set-volume -l 1.5 @DEFAULT_AUDIO_SINK@ 5%+
bindsym XF86AudioLowerVolume exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bindsym XF86AudioMute exec wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
bindsym XF86AudioMicMute exec wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle

alsamixer (sudo get install alsa-utils) shows the sound card's own controls, for when a channel is muted at the hardware level.

Configuration

PipeWire reads /usr/share/pipewire/*.conf; override parts of it with files in ~/.config/pipewire/pipewire.conf.d/ (for everyone: /etc/pipewire/pipewire.conf.d/). For example a fixed sample rate:

# ~/.config/pipewire/pipewire.conf.d/10-rate.conf
context.properties = {
    default.clock.rate = 48000
    default.clock.allowed-rates = [ 44100 48000 ]
}

Then dinitctl restart pipewire.

Troubleshooting

  • No sound, wpctl status fails: the user services are not running. Is exec dinit in your configuration, and is XDG_RUNTIME_DIR set (echo $XDG_RUNTIME_DIR should print /run/user/1000)?
  • Only "Dummy Output": no sound card was found, or you are not in the audio group. Check cat /proc/asound/cards.
  • Sound on HDMI instead of the speakers: choose the sink with wpctl set-default.
  • Newer laptops (Intel SOF): no sound card at all: the DSP needs firmware; install linux-firmware and reboot.
