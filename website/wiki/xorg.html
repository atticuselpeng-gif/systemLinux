Xorg

  • i3
  • Graphical session
  • Graphics drivers
Contents
  1. 1 Installing
  2. 2 Starting X
  3. 3 Configuration
  4. 4 Troubleshooting

Xorg is the X Window System server. It runs X11 window managers such as i3, dwm and Xfce. On systemLinux it runs without logind: it needs your user in the video and input groups.

Installing

$ sudo get install xorg-server xinit xf86-input-libinput setxkbmap xrandr

The meta port desktop-base installs xorg-server, xinit, xterm, DejaVu fonts and xdg-utils in one go. Graphics use the kernel's modesetting driver, which Xorg includes; xf86-video-amdgpu, xf86-video-nouveau, xf86-video-vesa and xf86-video-fbdev are in the ports tree for the cases where it is not enough.

Starting X

startx runs ~/.xinitrc, which starts your programs and, last, the window manager:

# ~/.xinitrc
dinit &                       # session services: D-Bus, PipeWire
setxkbmap fr
exec i3
$ startx

Without a ~/.xinitrc, startx opens a plain xterm.

Configuration

Xorg configures itself. For settings, add files to /etc/X11/xorg.conf.d/:

# /etc/X11/xorg.conf.d/30-touchpad.conf
Section "InputClass"
    Identifier "touchpad"
    MatchIsTouchpad "on"
    Driver "libinput"
    Option "Tapping" "on"
    Option "NaturalScrolling" "true"
EndSection
# /etc/X11/xorg.conf.d/00-keyboard.conf
Section "InputClass"
    Identifier "keyboard"
    MatchIsKeyboard "on"
    Option "XkbLayout" "fr"
EndSection

Screens: xrandr lists outputs and modes; xrandr --output HDMI-1 --auto --right-of eDP-1.

Troubleshooting

Xorg's log is ~/.local/share/xorg/Xorg.0.log (or /var/log/Xorg.0.log). Lines with (EE) are errors.

  • "no screens found": the GPU driver did not load; check ls /dev/dri and Graphics drivers.
  • Keyboard and mouse do nothing: install xf86-input-libinput, and check you are in input.
  • "Only console users are allowed to run the X server": run startx from a console login, not over SSH or with su.
