Leaving the chroot and rebooting

(chroot) # exit
# cd /
# umount -R /mnt
# cryptsetup close root                  # only with an encrypted root
# reboot

If umount says "target is busy", a shell or program still uses a file under /mnt: cd / in every console, or use umount -R -l /mnt. Remove the stick when the screen goes blank.

The first boot

GRUB shows its menu for three seconds, then the kernel and the initramfs start (with an encrypted root, the initramfs asks for the passphrase), and dinit brings the system up to a login prompt on tty1:

systemLinux v0.2.5 GNU/Linux (tty1)

mycomputer login:

Log in with your user name. If the boot stops somewhere, see Troubleshooting.

Checking the new system

$ sudo whoami                            # root: sudo works
$ dinitctl list                          # every service should be [{+}] (started)
$ findmnt /                              # root is your partition, mounted rw
$ free -h                                # zram swap is on
$ ping -c 3 kernel.org                   # the network works

On Wi-Fi, connect first: sudo nmcli device wifi connect "MyNetwork" password "secret".
