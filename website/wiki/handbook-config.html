All commands in this chapter run inside the chroot.

The EFI System Partition

On UEFI, mount the EFI System Partition now (it was left out while the stage was extracted):

(chroot) # mkdir -p /boot/efi
(chroot) # mount /dev/sda1 /boot/efi

fstab

/etc/fstab lists the file systems to mount at boot. The initramfs mounts / itself; everything else is mounted from here by the mount-fstab service, which also turns on swap partitions. Use UUIDs, because device names can change between boots. Show them with blkid:

(chroot) # blkid
/dev/sda1: UUID="A1B2-C3D4" TYPE="vfat" LABEL="EFI" ...
/dev/sda2: UUID="0f4c...e1" TYPE="ext4" LABEL="systemLinux" ...

Then write the file with nano /etc/fstab. For the UEFI layout:

# <file system>                          <mount point>  <type>  <options>          <dump> <pass>
UUID=0f4c...e1                             /              ext4    defaults,noatime   0      1
UUID=A1B2-C3D4                             /boot/efi      vfat    umask=0077         0      2

Add a line for each other partition:

UUID=...          /boot   ext4   defaults,noatime   0  2     # separate /boot (encrypted root)
UUID=...          /home   ext4   defaults,noatime   0  2     # separate /home
UUID=...          none    swap   defaults           0  0     # swap partition
/dev/mapper/root  /       ext4   defaults,noatime   0  1     # encrypted root: instead of the UUID= line for /
Tip: Let blkid fill in a UUID for you: echo "UUID=$(blkid -s UUID -o value /dev/sda2) / ext4 defaults,noatime 0 1" >> /etc/fstab.

Check it before you reboot: findmnt --verify reports mistakes. More in fstab.

Host name

(chroot) # echo mycomputer > /etc/hostname
(chroot) # printf '127.0.0.1\tlocalhost\n::1\t\tlocalhost\n127.0.1.1\tmycomputer\n' > /etc/hosts

Time zone

Time zones are named after a region and a city, see ls /usr/share/zoneinfo:

(chroot) # ln -sf ../usr/share/zoneinfo/Europe/Paris /etc/localtime
(chroot) # date

The hardware clock is read as UTC. Windows keeps it in local time; if you dual-boot with Windows, see System time. To keep the clock exact, install chrony after the first boot.

Locale

The locale sets the language of messages and the format of dates and numbers. C.UTF-8 is always there. To use another one, uncomment it in /etc/locale.gen and generate it:

(chroot) # nano /etc/locale.gen               # uncomment e.g. "fr_FR.UTF-8 UTF-8"
(chroot) # locale-gen
(chroot) # echo LANG=fr_FR.UTF-8 > /etc/locale.conf

Without a /etc/locale.conf the system uses C. echo LANG=C.UTF-8 > /etc/locale.conf is a good choice if you want English with full Unicode support. See Locale.

Console keyboard and font

Set the layout you loaded in the live system, so it is used at every boot:

(chroot) # echo KEYMAP=fr > /etc/vconsole.conf

Add FONT=NAME for a console font from /usr/share/consolefonts. The console-setup service reads this file at boot. See Linux console.

Network

NetworkManager starts at every boot and connects Ethernet by itself. To take the Wi-Fi network you joined in the live system along, copy its saved connection from outside the chroot (in another console: Alt+F2, or after exit):

# cp -a /etc/NetworkManager/system-connections/. /mnt/etc/NetworkManager/system-connections/

Otherwise connect with nmcli after the first boot. See Network configuration.

Root password

(chroot) # passwd
Warning: Without a root password you cannot log in as root, and if you forget to create a user too, you cannot log in at all. Fix that from the live system with Recovery.

Your user account

Use a normal account for daily work. The groups give access to what a desktop needs:

(chroot) # useradd -m -G wheel,video,audio,input -s /bin/bash alex
(chroot) # passwd alex
GroupGives
wheelsudo (with the rule below) and su
videothe GPU and seatd (needed for Sway)
audiosound devices
inputkeyboards, mice and touchpads (libinput)

See Users and groups.

sudo

Let the wheel group run commands as root with sudo:

(chroot) # echo '%wheel ALL=(ALL:ALL) ALL' > /etc/sudoers.d/10_wheel
(chroot) # chmod 440 /etc/sudoers.d/10_wheel
(chroot) # visudo -c

See sudo.

Services

A normal boot needs nothing extra: devices, the network, D-Bus, swap in memory and a login on tty1 are all started by default. To start more at every boot, link them into /etc/dinit.d/boot.d. For example the SSH server:

(chroot) # ln -s ../sshd /etc/dinit.d/boot.d/sshd

On the running system dinitctl enable sshd does the same. See dinit.

Tip: systemlinux-provision --user alex / creates the account, its groups and the sudo rule in one go (it asks for the password twice). It is what the quick installer uses.
