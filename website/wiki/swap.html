Swap

Swap is disk (or compressed memory) the kernel uses when RAM runs out. On a source-based system it matters most while building big programs.

zram (default)

Every systemLinux system turns on a 4 GB zram device at boot: swap that lives in RAM itself, compressed with zstd. Pages that are not in use get squeezed to a third or less of their size, which is much faster than swapping to disk. The zram service does it; see it with:

$ swapon --show
NAME       TYPE      SIZE USED PRIO
/dev/zram0 partition   4G   0B 32767

To turn it off, disable the service's link: it is started by boot directly, so edit /etc/dinit.d/boot and remove the line waits-for = zram. To change its size, edit 4G in /usr/lib/dinit/zram.

Swap partition

Create it when partitioning (Handbook chapter 3), or on any free partition:

$ sudo mkswap -L swap /dev/sdXN
$ sudo swapon /dev/sdXN

and add it to fstab so it is used at every boot:

UUID=...   none   swap   defaults   0 0

zram has the highest priority (32767), so the kernel fills it first and only then the disk.

Swap file

Without a free partition, a file works as well (on ext4 and XFS):

$ sudo dd if=/dev/zero of=/swapfile bs=1M count=8192 status=progress
$ sudo chmod 600 /swapfile
$ sudo mkswap /swapfile
$ sudo swapon /swapfile
$ echo '/swapfile none swap defaults 0 0' | sudo tee -a /etc/fstab

On Btrfs a swap file needs extra steps (btrfs filesystem mkswapfile).

How much?

With 8 GB of RAM or more, zram alone is usually enough. With less, or for very big builds (browsers, LLVM, Qt WebEngine), add 8 GB of disk swap, and build with fewer jobs (get install -j 2).

Note: Hibernation (suspend to disk) is not set up: the initramfs does not resume from swap.
