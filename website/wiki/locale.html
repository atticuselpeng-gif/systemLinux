Locale

A locale sets the language of program messages and the way dates, times, numbers and money are written, and which characters are letters. It is chosen with environment variables such as LANG.

Available locales

C and C.UTF-8 are built into the C library and always work. Others have to be generated first:

$ locale -a                              # the ones that exist

Generating locales

List the ones you want in /etc/locale.gen, one per line, as NAME CHARSET (the file has examples), then run locale-gen:

$ echo 'fr_FR.UTF-8 UTF-8' | sudo tee -a /etc/locale.gen
$ echo 'en_US.UTF-8 UTF-8' | sudo tee -a /etc/locale.gen
$ sudo locale-gen

All supported names are in /usr/share/i18n/SUPPORTED.

Setting the locale

The system-wide setting is /etc/locale.conf, read at every login by /etc/profile.d/locale.sh:

LANG=fr_FR.UTF-8

Single categories can differ. English messages with French dates, numbers and paper size:

LANG=en_US.UTF-8
LC_TIME=fr_FR.UTF-8
LC_NUMERIC=fr_FR.UTF-8
LC_MONETARY=fr_FR.UTF-8
LC_PAPER=fr_FR.UTF-8

Log out and in again, then check with locale. One user can override it in ~/.profile (export LANG=de_DE.UTF-8).

Note: Translations of program messages are not part of the base system, so most messages stay in English whatever LANG says; formats (dates, decimal separator) do change. Ports built with their translations bring their own.

Troubleshooting

  • "Cannot set LC_ALL to default locale" / "setlocale: LC_CTYPE: cannot change locale": the locale in /etc/locale.conf was not generated. Add it to /etc/locale.gen and run locale-gen.
  • Accented characters show as ? on the console: use a UTF-8 locale and a console font that has the characters (Linux console).
