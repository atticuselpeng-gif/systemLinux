System time

  3. 3 Hardware clock in UTC or local time
  4. 4 Time synchronization

A computer has two clocks: the hardware clock (RTC) on the mainboard, which runs when the computer is off, and the system clock kept by the kernel. At boot the kernel sets the system clock from the hardware clock.

Time zone

The time zone is the link /etc/localtime:

$ ls /usr/share/zoneinfo                  # regions
$ ls /usr/share/zoneinfo/Europe
$ sudo ln -sf ../usr/share/zoneinfo/Europe/Paris /etc/localtime
$ date

tzselect helps you find the right name. One user can use another zone by setting TZ=America/New_York in their shell.

Setting the time

$ date                                   # local time
$ date -u                                # UTC
$ sudo date -s '2026-10-17 14:30:00'     # set the system clock (local time)
$ sudo hwclock --systohc                 # copy it to the hardware clock
$ sudo hwclock --show                    # read the hardware clock

Hardware clock in UTC or local time

systemLinux reads the hardware clock as UTC, as Linux normally does. Windows keeps it in local time, so after booting Windows the Linux clock is off by your offset from UTC (and the other way round). The best fix is to make Windows use UTC as well: in Windows, run as administrator

reg add "HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /d 1 /t REG_DWORD /f

and set the clock once in either system. Time synchronization (below) also corrects it within seconds after boot.

Time synchronization

The clock drifts by seconds a week. chrony keeps it exact over the network:

$ sudo get install chrony
$ sudo dinitctl enable chronyd
$ chronyc tracking                       # how far off the clock is
$ chronyc sources                        # the time servers in use

The port's /etc/chrony.conf uses pool.ntp.org, corrects a large error at boot by stepping the clock, and copies the time to the hardware clock every 11 minutes. To use other servers, replace the pool line (for example server time.cloudflare.com iburst) and restart: sudo dinitctl restart chronyd.
