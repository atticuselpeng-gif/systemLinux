What you get

A minimal console system. The live ISO is installer media only: kernel plus the bare minimum to install.

Minimal live ISO

The live image is only the kernel and what the installer needs: dinit, eudev, NetworkManager, disk and boot tools. No desktop, daemons, firmware bundles, docs or locale packs.

Install it yourself

The handbook lists every command. If you'd rather not type them, systemlinux-install runs the same steps. Use a whole disk, or a partition you've already freed up. It boots from a USB stick or Ventoy, in UEFI or legacy BIOS mode.

Build what you need

get install NAME builds a package from the ports tree with everything it needs, installs it into /usr and records every file, so get remove undoes it exactly.

Plain dinit

Services are small dinit service files in /etc/dinit.d/. dinitctl starts, stops and lists them.

Up-to-date kernel

Ubuntu’s newest generic kernel with its full set of driver modules: Intel, AMD and open-source NVIDIA graphics, Wi-Fi, Bluetooth, storage, sound and laptop hardware load automatically.

What's in the image

KernelLinux 7.3.0 (Ubuntu 26.10 linux-image-generic, the newest Ubuntu kernel at build time) with its full module tree; drivers load automatically. No firmware bundled
Initdinit 0.20.0 as PID 1 and the only init system; systemd is removed completely and eudev is the device manager. The base services are service files in /etc/dinit.d/
Servicesdinit and NetworkManager only. No bundled desktop or extra daemons
UserlandGNU bash 5.3 as /bin/sh, GNU coreutils, tar, sed and gawk on glibc
Softwareget, the package tool, and the ports tree in /usr/ports (see Packages)
InstallerNo GUI. The handbook has every command, and systemlinux-install is a terminal script that runs the same steps: whole disk or an existing partition, with optional LUKS encryption
BootGRUB 2.12, hybrid legacy BIOS and UEFI x86_64. Live entries: normal, copy to RAM, serial console, debug shell
MemoryAbout 3 GB; the “copy to RAM” entry needs the whole 1.9 GB image in memory on top
