get

get is the systemLinux package tool. It builds packages from source using the ports tree in /usr/ports, installs them into /usr like the base system, and records every installed file (the base system's too), so a package never overwrites another one's files and removing a package deletes exactly what it installed.

get install sway            # build sway and everything it needs (get sway works too)
get remove sway             # uninstall (refused while another package needs it)
get autoremove              # remove dependencies nothing needs any more
get search editor           # search names and descriptions
get info helix              # recipe, dependencies, status
get list                    # installed packages (* = installed on request)
get files sway              # files a package owns
get sync                    # update the ports tree from the latest release
get install URL             # build a source tarball that has no recipe
get profile build-toolchain # unpack a prebuilt profile
  • Dependencies. A port's requires are built first, in order. Anything the base system already has is not rebuilt.
  • Build systems. configure, autotools, CMake, Meson, make, Python (pip), Cargo, Go, Perl, fonts, or a port's own build script.
  • Services. Daemons come with dinit service files: dinitctl enable NAME after installing.
  • Safe. Sources are checked against the recipe's sha256. Builds are staged with DESTDIR, and a package never overwrites a file another package owns.
  • Options. -j N parallel jobs, -k keep the build folder, -f force.

Ports

The ports tree has about 870 recipes: core utilities, networking, compilers and toolchains (GCC, LLVM, Rust, Go), editors, shells, libraries, the X.Org and Wayland stacks with Mesa, window managers (i3, sway, bspwm, dwm), a login manager (greetd), PipeWire audio, media, security, databases, games and developer tools.

Want to add a program? See Packaging.
